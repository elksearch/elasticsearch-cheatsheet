## 🧠 Core Concepts

```
PAINLESS = ES's own scripting language
  → Java-like syntax (but safer and faster)
  → Sandboxed (no file I/O, no network, no reflection)
  → Compiled and cached → fast after first execution
  → Type-inferred (like Java with type inference)

WHERE PAINLESS IS USED:
  ✅ Runtime fields (compute at query time)
  ✅ Ingest pipelines (script processor)
  ✅ Search queries (script query, function score)
  ✅ Aggregations (scripted metric, bucket script)
  ✅ Sort (script-based sort)
  ✅ Update by query / Delete by query
  ✅ Watcher (transform, condition scripts)
  ✅ ML (custom features, filters)
  ✅ Transforms

CONTEXTS:
  Each use case = different context = different variables available
  filter   → ctx, params → boolean return
  score    → doc, params, _score → double return
  update   → ctx._source, params → modifies document
  ingest   → ctx (= document fields) → modifies document
  field    → doc, params → value return (for script fields)
  runtime  → emit(value) → values for runtime field
```

## 📝 Part 1 - Painless Syntax

### Data Types

```painless
// Primitive types
boolean flag = true;
byte b = 10;
short s = 1000;
int i = 42;
long l = 100000L;
float f = 3.14f;
double d = 3.14159;
char c = 'A';

// String
String name = "Elasticsearch";
String template = "Service: " + name;

// Def (dynamic type — use sparingly)
def value = doc['field'].value;   // type inferred at runtime
def list = new ArrayList();

// Lists and Maps
List<String> services = new ArrayList();
services.add("nginx");
services.add("api");

Map<String, Integer> counts = new HashMap();
counts.put("errors", 42);
counts.put("warnings", 10);
int errorCount = counts.get("errors");

// Arrays
int[] scores = new int[]{1, 2, 3};
```

### Control Flow

```painless
// If-else
if (doc['http.response.status_code'].size() > 0) {
    int status = doc['http.response.status_code'].value;
    if (status >= 500) {
        return "server_error";
    } else if (status >= 400) {
        return "client_error";
    } else if (status >= 300) {
        return "redirect";
    } else {
        return "success";
    }
}

// Ternary
String level = doc['log.level'].value == "ERROR" ? "high" : "low";

// For loop
int total = 0;
for (int i = 0; i < 10; i++) {
    total += i;
}

// For-each
List<String> tags = doc['tags'];
for (String tag : tags) {
    if (tag == "critical") {
        return true;
    }
}

// While
int count = 0;
while (count < doc['items'].size()) {
    count++;
}
```

### Null Safety

```painless
// WRONG — throws NullPointerException if field missing
int status = doc['http.response.status_code'].value;

// CORRECT — check size() first
if (doc['http.response.status_code'].size() > 0) {
    int status = doc['http.response.status_code'].value;
}

// For _source fields — use null check
if (ctx._source.containsKey('nested_field')) {
    String value = ctx._source['nested_field'];
}

// Safe navigation with def
def status = doc['http.response.status_code'].size() > 0
    ? doc['http.response.status_code'].value
    : null;

if (status != null && status >= 500) {
    // process error
}
```

## 🔧 Part 2 - Script Context: Ingest Pipeline

```bash
# Script processor in ingest pipeline
PUT _ingest/pipeline/painless-enrichment
{
  "processors": [
    {
      "script": {
        "lang": "painless",
        "source": """
          // Access fields via ctx
          // ctx = entire document (mutable)

          // 1. Compute derived field
          if (ctx.containsKey('event') && ctx.event.containsKey('duration')) {
            long duration = ctx.event.duration;
            if (duration < 100) {
              ctx['event']['duration_category'] = 'fast';
            } else if (duration < 1000) {
              ctx['event']['duration_category'] = 'normal';
            } else if (duration < 5000) {
              ctx['event']['duration_category'] = 'slow';
            } else {
              ctx['event']['duration_category'] = 'very_slow';
            }
          }

          // 2. Parse and enrich
          if (ctx.containsKey('http') && ctx.http.containsKey('response')) {
            int status = ctx.http.response.status_code;
            ctx['event']['outcome'] = status < 400 ? 'success' : 'failure';
          }

          // 3. Add metadata
          ctx['event']['ingested'] = params._ingest.timestamp;
          ctx['processing']['version'] = params.version;
        """,
        "params": {
          "version": "1.0"
        }
      }
    }
  ]
}

# Test with simulate
POST _ingest/pipeline/painless-enrichment/_simulate
{
  "docs": [
    {
      "_source": {
        "event": { "duration": 250 },
        "http": { "response": { "status_code": 200 } },
        "message": "Request processed"
      }
    }
  ]
}
```

## 🔍 Part 3 - Script Context: Search

### Script Query (Filter Context)

```bash
# Find documents where computed value meets condition
GET logs-nginx-production/_search
{
  "query": {
    "bool": {
      "filter": [
        {
          "script": {
            "script": {
              "lang": "painless",
              "source": """
                // Return true = include document
                // Return false = exclude document

                // Example: filter by response time category
                if (doc['event.duration'].size() == 0) return false;
                long duration = doc['event.duration'].value;
                return duration > params.threshold;
              """,
              "params": {
                "threshold": 5000
              }
            }
          }
        }
      ]
    }
  }
}
// NOTE: Script queries are SLOW — avoid in hot path
// Use range query instead whenever possible
```

### Script Score (Function Score)

```bash
GET logs-nginx-production/_search
{
  "query": {
    "function_score": {
      "query": {
        "match": { "message": "connection timeout" }
      },
      "script_score": {
        "script": {
          "lang": "painless",
          "source": """
            // Boost recent documents
            double score = _score;

            // Recency boost (exponential decay)
            if (doc['@timestamp'].size() > 0) {
              long ageMs = System.currentTimeMillis() - doc['@timestamp'].value.toInstant().toEpochMilli();
              double ageDays = ageMs / 86400000.0;
              score *= Math.exp(-0.1 * ageDays);
            }

            // Severity boost
            if (doc['log.level'].size() > 0) {
              String level = doc['log.level'].value;
              if (level == 'ERROR') {
                score *= 3.0;
              } else if (level == 'WARN') {
                score *= 2.0;
              }
            }

            // Payment service boost
            if (doc['service.name'].size() > 0 &&
                doc['service.name'].value == params.critical_service) {
              score *= params.critical_boost;
            }

            return Math.max(score, 0.0);
          """,
          "params": {
            "critical_service": "payment-service",
            "critical_boost": 2.5
          }
        }
      }
    }
  }
}
```

### Script Fields (Return Computed Values)

```bash
GET logs-nginx-production/_search
{
  "query": { "match_all": {} },
  "script_fields": {
    "duration_seconds": {
      "script": {
        "lang": "painless",
        "source": "doc['event.duration'].size() > 0 ? doc['event.duration'].value / 1000.0 : null"

    },
    "status_category": {
      "script": {
        "lang": "painless",
        "source": """
          if (doc['http.response.status_code'].size() == 0) return 'unknown';
          int status = doc['http.response.status_code'].value;
          if (status < 300) return 'success';
          if (status < 400) return 'redirect';
          if (status < 500) return 'client_error';
          return 'server_error';
        """
      }
    },
    "day_of_week": {
      "script": {
        "lang": "painless",
        "source": """
          if (doc['@timestamp'].size() == 0) return 'unknown';
          ZonedDateTime dt = doc['@timestamp'].value;
          return dt.getDayOfWeek().getDisplayName(
            java.time.format.TextStyle.FULL,
            Locale.ROOT
          );
        """
      }
    }
  }
}
```

## 🏃 Part 4 - Script Context: Runtime Fields

```bash
PUT logs-nginx-production/_mapping
{
  "runtime": {
    # Runtime field: compute at query time, not stored
    "error_severity": {
      "type": "keyword",
      "script": {
        "lang": "painless",
        "source": """
          if (doc['log.level'].size() == 0) {
            emit('unknown');
            return;
          }
          String level = doc['log.level'].value;
          if (level == 'ERROR') emit('high');
          else if (level == 'WARN') emit('medium');
          else emit('low');
        """
      }
    },

    "response_time_ms": {
      "type": "double",
      "script": {
        "lang": "painless",
        "source": """
          if (doc['event.duration'].size() > 0) {
            emit(doc['event.duration'].value / 1000.0);
          }
        """
      }
    },

    "is_business_hours": {
      "type": "boolean",
      "script": {
        "lang": "painless",
        "source": """
          if (doc['@timestamp'].size() == 0) {
            emit(false);
            return;
          }
          ZonedDateTime dt = doc['@timestamp'].value.withZoneSameInstant(
            java.time.ZoneId.of('Asia/Kolkata')
          );
          int hour = dt.getHour();
          int dow = dt.getDayOfWeek().getValue();
          // Mon-Fri (1-5), 9am-6pm
          emit(dow >= 1 && dow <= 5 && hour >= 9 && hour < 18);
        """
      }
    },

    "url_path_prefix": {
      "type": "keyword",
      "script": {
        "lang": "painless",
        "source": """
          if (doc['url.path'].size() == 0) return;
          String path = doc['url.path'].value;
          String[] parts = / /.split(path);
          if (parts.length > 1) {
            emit('/' + parts[1]);
          } else {
            emit('/');
          }
        """
      }
    }
  }
}

# Use runtime field in search
GET logs-nginx-production/_search
{
  "query": {
    "term": { "error_severity": "high" }
  },
  "aggs": {
    "by_severity": {
      "terms": { "field": "error_severity" }
    }
  }
}
```

## 📊 Part 5 - Script Context: Aggregations

### Scripted Metric Aggregation

```bash
GET logs-nginx-production/_search
{
  "size": 0,
  "aggs": {
    "custom_error_rate": {
      "scripted_metric": {
        "init_script": """
          state.total = 0;
          state.errors = 0;
          state.total_duration = 0;
        """,
        "map_script": """
          state.total++;
          if (doc['log.level'].size() > 0 && doc['log.level'].value == 'ERROR') {
            state.errors++;
          }
          if (doc['event.duration'].size() > 0) {
            state.total_duration += doc['event.duration'].value;
          }
        """,
        "combine_script": """
          // Runs on each shard — combine shard-level state
          return state;
        """,
        "reduce_script": """
          // Runs on coordinator — combine all shard states
          long total = 0;
          long errors = 0;
          long totalDuration = 0;

          for (s in states) {
            total += s.total;
            errors += s.errors;
            totalDuration += s.total_duration;
          }

          return [
            'total': total,
            'errors': errors,
            'error_rate_percent': total > 0 ? (double)errors / total * 100 : 0,
            'avg_duration_ms': total > 0 ? (double)totalDuration / total : 0
          ];
        """
      }
    }
  }
}
```

### Script Sort

```bash
GET logs-nginx-production/_search
{
  "sort": [
    {
      "_script": {
        "type": "number",
        "script": {
          "lang": "painless",
          "source": """
            // Sort by composite score: error weight + recency
            double score = 0;

            if (doc['log.level'].size() > 0) {
              String level = doc['log.level'].value;
              if (level == 'ERROR') score += 100;
              else if (level == 'WARN') score += 50;
            }

            if (doc['event.duration'].size() > 0) {
              score += doc['event.duration'].value / 100.0;
            }

            return score;
          """
        },
        "order": "desc"
      }
    }
  ]
}
```

## 🔄 Part 6 - Script Context: Update

```bash
# Update by query with script
POST logs-nginx-production/_update_by_query
{
  "query": {
    "term": { "status": "pending" }
  },
  "script": {
    "lang": "painless",
    "source": """
      // ctx._source = document being updated
      ctx._source.status = 'processed';
      ctx._source.processed_at = params.now;
      ctx._source.retry_count = (ctx._source.containsKey('retry_count'))
        ? ctx._source.retry_count + 1
        : 1;

      // Add to array
      if (!ctx._source.containsKey('processing_history')) {
        ctx._source.processing_history = new ArrayList();
      }
      ctx._source.processing_history.add(params.now);

      // Remove field
      ctx._source.remove('temp_field');

      // Conditional update
      if (ctx._source.containsKey('error_count') &&
          ctx._source.error_count > params.max_errors) {
        ctx._source.status = 'failed';
        ctx.op = 'noop';  // don't update if already failed (optimistic)
      }
    """,
    "params": {
      "now": "2026-05-19T10:00:00Z",
      "max_errors": 5
    }
  }
}
```

## ⚡ Part 7 - Performance & Caching

### Script Compilation and Caching

```
HOW CACHING WORKS:
  First execution → Painless compiles script to bytecode → cached
  Subsequent executions → cached bytecode → near-native speed

CACHE SETTINGS:
  script.cache.max_size:    75 (max cached scripts)
  script.cache.expire:      5m (time before eviction)
  script.max_compilations_rate: 75/5m (compilation rate limit)
```

```bash
# Check script cache stats
GET _nodes/stats/script

# Response:
# compilations: number of times scripts were compiled
# cache_evictions: number of evictions
# compilation_limit_triggered: how often rate limit hit
```

### Performance Best Practices

```painless
// SLOW: Access same doc field multiple times
if (doc['service.name'].size() > 0) {
    if (doc['service.name'].value == 'api') {
        // ...
    }
    if (doc['service.name'].value.startsWith('pay')) {
        // ...
    }
}

// FAST: Store in local variable once
if (doc['service.name'].size() > 0) {
    String service = doc['service.name'].value;  // access once
    if (service == 'api') {
        // ...
    }
    if (service.startsWith('pay')) {
        // ...
    }
}

// SLOW: String concatenation in loop
String result = '';
for (int i = 0; i < list.size(); i++) {
    result += list.get(i) + ',';  // creates new String each iteration
}

// FAST: StringBuilder
StringBuilder sb = new StringBuilder();
for (String item : list) {
    if (sb.length() > 0) sb.append(',');
    sb.append(item);
}
String result = sb.toString();
```

### Parameterize Scripts (Critical for Caching!)

```bash
# WRONG — different script per value = new compilation each time!
{
  "script": {
    "source": "doc['price'].value > 100"  // hardcoded value
  }
}

# CORRECT — same script, different params = compiled once, reused!
{
  "script": {
    "source": "doc['price'].value > params.threshold",
    "params": { "threshold": 100 }   // value via params
  }
}
```

### Stored Scripts (Pre-compiled, Reusable)

```bash
# Store script in cluster
PUT _scripts/calculate-error-rate
{
  "script": {
    "lang": "painless",
    "source": """
      if (params.total == 0) return 0;
      return (double)params.errors / params.total * 100;
    """
  }
}

# Use stored script
GET logs-nginx-production/_search
{
  "size": 0,
  "aggs": {
    "error_calc": {
      "bucket_script": {
        "buckets_path": {
          "total": "total_requests",
          "errors": "error_requests"
        },
        "script": {
          "id": "calculate-error-rate"
        }
      }
    }
  }
}

# List stored scripts

# Delete stored script

```

## 🛡️ Part 8 — Painless Security

```
SANDBOX RESTRICTIONS (cannot do in Painless):
  ❌ File I/O (no reading/writing files)
  ❌ Network calls (no HTTP requests)
  ❌ System properties access
  ❌ Reflection (no Class.forName())
  ❌ Thread creation
  ❌ Process spawning
  ❌ External library imports (only Java stdlib + ES APIs)

ALLOWED:
  ✅ Java stdlib: String, Math, List, Map, Date, etc.
  ✅ ES document access: doc, ctx, _source
  ✅ Math operations
  ✅ String manipulation
  ✅ Collection operations
  ✅ Date/time operations

WHY SANDBOXED?
  → Scripts run inside ES process
  → Malicious script could crash ES, leak data, or hack cluster
  → Sandbox prevents all of this
```

## ❌ Common Mistakes & Fixes

| Mistake | Impact | Fix |
|---|---|---|
| Not checking `.size() > 0` before `.value` | NullPointerException | Always check `doc['field'].size() > 0` |
| Hardcoded values in scripts | Cache miss — recompiles every time | Use `params` for any varying values |
| Accessing `doc['text_field']` | Returns nothing (text not in doc values) | Use `.keyword` subfield or `_source` |
| Script in query (not filter) | Slow — runs on every doc | Move to filter context |
| String concatenation in loop | O(n²) performance | Use StringBuilder |
| Not using stored scripts for reuse | Repeated compilation | Store reusable scripts with PUT _scripts/ |
| Accessing _source in aggregations | Much slower than doc values | Use `doc['field']` in aggs when possible |
| Missing `return` statement | Script returns null | All code paths must have return/emit |
| Not testing in Painless Lab first | Hard to debug in production | Always test in Kibana Painless Lab |
| Using `def` everywhere | Slower than typed variables | Use explicit types: `String`, `int`, `long` |

## 💡 Key Principles

```
1. Always check doc['field'].size() > 0 before accessing .value
   → NullPointerException = most common Painless bug

2. Use params for values, never hardcode in source
   → Parameterized scripts = compiled once, reused infinitely

3. Use doc['field'] not _source for aggregations and filters
   → doc values = in memory, _source = disk read

4. Stored scripts for frequently reused logic
   → PUT _scripts/my-script → use by ID

5. Painless Lab in Kibana before production
   → Test all scripts interactively before deploying

6. Explicit types faster than def
   → String s = "x" faster than def s = "x"

7. Script queries are slow — last resort
   → Range/term/bool queries are indexed → fast
   → Script query = sequential scan → slow

8. StringBuilder for string concatenation in loops
   → String += in loop = O(n²), StringBuilder = O(n)

9. Script score is pre-computed per shard
   → Still faster than script filter (which runs serially)

10. Keep scripts short and single-purpose
    → Complex logic = hard to debug + maintain
    → Split into multiple processors/fields
```
